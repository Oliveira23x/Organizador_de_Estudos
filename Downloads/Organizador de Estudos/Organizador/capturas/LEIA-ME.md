# Capturas das funcionalidades

Imagens capturadas da aplicação real no **Expo web**, usando layout mobile de **390 × 844 pixels** e escala 2×. Os PNGs têm 780 × 1.688 pixels.

| Arquivo | Funcionalidade |
| --- | --- |
| `01_resumo.png` | Tempo semanal, tempo total, quantidade de sessões e sequência |
| `02_indicadores.png` | Gráfico diário e progresso automático das metas |
| `03_disciplinas.png` | Disciplinas, cores, totais, edição e exclusão |
| `04_validacao.png` | Mensagem para duração inválida e formulário preenchido |
| `05_sessoes.png` | Busca, filtros por disciplina e período, ordenação e total |
| `06_metas.png` | Filtros de metas, progresso e status de conclusão |
| `07_cadastro_sessao.png` | Formulário de uma sessão de estudo |
| `08_historico_sessoes.png` | Histórico com conteúdo, disciplina, data e duração |

As telas principais usam os dados opcionais de exemplo. A captura de validação inclui registros temporários criados durante a conferência do CRUD. Ao iniciar o projeto pela primeira vez, o banco começa vazio; o botão de exemplos é opcional.

Para comprovar execução no dispositivo escolhido para a apresentação, faça também capturas diretamente nele.
